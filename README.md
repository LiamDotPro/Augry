# Augry

A desktop app for running coding agents side by side, reviewing what they
change, and turning routine work into processes. Windows, macOS and Linux.

**[Download Augry](https://augry.dev/download/)** · [augry.dev](https://augry.dev)

This repository holds Augry's releases and its issue tracker. The installers
for every version are on the [Releases page](../../releases), and installed
copies of Augry update themselves from here.

## Found a bug, or want something?

[Open an issue](../../issues/new). Say which version you are on (Settings,
General) and your operating system.
